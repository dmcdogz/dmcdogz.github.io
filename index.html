HOME LAB PROJECT 01Practice plan

No-Boot Desktop PC Diagnosis

Problem: Desktop powers on, fans spin, but there is no display.

Environment: Record motherboard, CPU, RAM, GPU, PSU, monitor, and operating system once tested.

Approach:

  1. Check power switch, cable, monitor input, and display cable.
  2. Observe motherboard debug LEDs or beep indicators.
  3. Test a minimal hardware configuration.
  4. Test memory modules and slots individually.
  5. Check GPU seating and supported display outputs.
  6. Clear CMOS only according to the motherboard manual.

Solution / Result: Record the actual fault, verified repair, successful POST/boot status, diagnosis time, and any part cost. Do not assume a failed component before testing.

Lessons / Time: Add what you learned and the actual time taken after the test.

HOME LAB PROJECT 02Practice plan

Slow Windows Laptop Troubleshooting

Problem: Laptop starts slowly or becomes unresponsive during light use.

Environment: Record Windows edition/build, CPU, RAM, and storage type.

Approach:

  1. Check Task Manager and Resource Monitor for resource usage.
  2. Check storage health with a reputable drive-health utility.
  3. Review startup apps and available storage space.
  4. Run Windows system-file repair tools when appropriate.
  5. Scan with Windows Security and install supported updates.
  6. Compare results before and after each change.

Solution / Result: Document only the change that actually helped. Record boot time before/after and any hardware cost. Back up data before storage replacement or migration.

Lessons / Time: Record lessons and actual time taken.

HOME LAB PROJECT 03Practice plan

Home Network Dropouts & Slow Wi-Fi

Problem: Intermittent disconnections or weak Wi-Fi in parts of the home.

Environment: Record router/access point model, ISP plan, client device, and room locations.

Approach:

  1. Compare wired and wireless connection tests.
  2. Use ping, tracert, and ipconfig to narrow down the issue.
  3. Check signal strength and channel congestion with a Wi-Fi analyzer.
  4. Review router firmware, DHCP settings, and possible IP conflicts.
  5. Inspect Ethernet cables and connectors.

Solution / Result: Record the change actually made and compare packet loss, latency, speed, and signal strength before/after.

Lessons / Time: Add findings and actual time taken.

HOME LAB PROJECT 04Practice plan

Windows OS Installation on a Newly Formatted PC

Problem: A PC needs a clean Windows installation after formatting or drive replacement.

Environment: Record PC specifications, Windows edition, installation media source, and license type.

Approach:

  1. Confirm the owner has backed up important files and has a valid Windows license or digital entitlement.
  2. Check hardware compatibility and obtain installation media from Microsoft's official source.
  3. Install the correct Windows edition for the device's license.
  4. Install manufacturer-supported drivers and Windows updates.
  5. Check Device Manager, Windows Security, audio, network, and display functions.
  6. Verify activation in Settings → System → Activation.

Solution / Result: Record installation status, activation status, drivers installed, and tests passed. Use a genuine product key or valid digital license; never use activation bypasses or unauthorized keys.

Lessons / Time: Record actual time taken and any issues encountered. If performed for a client, obtain permission before publishing identifying details.

HOME LAB PROJECT 05Practice plan

Local Account & Data Recovery Basics

Problem: A test account is inaccessible or a test drive is not detected.

Environment: Use a spare/test machine and non-important sample data only.

Approach:

  1. Use the official Microsoft account recovery process where applicable.
  2. Check drive cables, ports, BIOS/UEFI detection, and Disk Management.
  3. Review drive health before attempting repairs.
  4. Make a sector-level image of a failing test drive before recovery attempts.
  5. Recover sample files from the image and verify them.

Solution / Result: Record what was recoverable and what was not. Never promise complete recovery; refer physically failing or important drives to a qualified recovery service.

Lessons / Time: Record actual time and backup recommendations.
