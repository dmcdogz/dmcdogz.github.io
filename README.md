# IT Support Case Study Documentation

Use this folder to publish one Markdown file per case study after you have actually completed and tested it.

## Required format

1. **Title**
2. **Environment** — hardware, OS, and tools
3. **Problem** — what happened and how it was observed
4. **Approach** — checks performed, in order
5. **Solution** — the verified cause and fix
6. **Result** — measurable before/after evidence
7. **Lessons learned**
8. **Time taken**

## Evidence checklist

- [ ] Date and test environment recorded
- [ ] Original problem documented
- [ ] Steps and commands recorded accurately
- [ ] Before/after measurements included where possible
- [ ] Original screenshots or photos added
- [ ] Personal data, serial numbers, Wi-Fi passwords, and account details hidden
- [ ] Client permission obtained before publishing any client-related material
- [ ] No invented results, testimonials, or client names

## Windows installation note

Only install Windows on devices you own or are authorized to service. Use official Microsoft installation media and a valid product key or digital license. Verify activation in Windows Settings. Do not use unauthorized activation tools or bypasses.
