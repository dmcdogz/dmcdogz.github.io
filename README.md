# Duncan Jake M. Macasu — Personal Portfolio

Responsive dark-themed portfolio for Duncan Jake M. Macasu, a BSIT student at Nueva Vizcaya State University (NVSU), interested in IT support, network administration, software development, and cloud technology.

## Features
- Responsive mobile, tablet, and desktop layout
- About and education sections
- Skills and project-topic cards
- Email and GitHub profile links
- Mobile navigation menu
- Accessibility focus styles and reduced-motion support
- Plain HTML, CSS, and JavaScript; no build tools or dependencies

## Preview locally
Download or clone the repository, then open `index.html` in your browser. You can also use Visual Studio Code's Live Server extension.

## Publish with GitHub Pages

### Recommended: main profile website
1. Sign in to GitHub as `Dmcdogz`.
2. Create a **public** repository named exactly `Dmcdogz.github.io`.
3. Upload `index.html`, `styles.css`, `script.js`, `README.md`, and `.nojekyll` to the repository root.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then click **Save**.
7. Wait a few minutes and visit `https://Dmcdogz.github.io`.

This is the expected GitHub Pages URL pattern, not a claim that the site is already published.

### Alternative: another repository
1. Create a public repository such as `portfolio`.
2. Upload the website files to its root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. The expected URL pattern is `https://Dmcdogz.github.io/portfolio/`.

## Customize

- Update colors and layout in `styles.css`.
- Update mobile navigation behavior in `script.js`.
- Add project repository/demo links only after verifying the links.
